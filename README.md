# Sky-Charge-EV
Project Name:Sky-Charge-EV

Description:
EV Rescue platform provides quick emergency battery assistance for
stranded EV drivers.
The system detects the user’s location using GPS and identifies the
nearest energy station or available helper.
Multiple delivery options such as car-pool assistance, service vehicles,
or drone delivery are used to transport portable battery packs.
A real-time monitoring dashboard tracks requests, battery status, and
delivery progress for efficient management.

Live Website:
https://purple-juice-delivery.lovable.app

Technologies Used:
ESP32
INA219 current sensor
Solar panel
Web application
